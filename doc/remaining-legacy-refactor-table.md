# Отчет: что осталось от старого подхода и что рефакторить дальше

Дата анализа: 2026-06-02

Область: `core`, `project`, `htdocs`, `cli`; без `vendor` и `legacy_assets`.

Важно: отчет построен по текущей dirty рабочей копии. В дереве уже есть большой незакоммиченный слой PHP 8/DI/adapters модернизации, поэтому это срез текущего workspace, а не чистого git baseline.
